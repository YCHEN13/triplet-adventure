# Triplet Adventure — narration script

Written and illustrated by **Yimei Chen**

## Production notes

- Audience: young children.
- Read slowly, warmly, and clearly. Leave a short pause between paragraphs.
- **Zoey** is the first-person narrator (“I”). Use the same voice for Zoey’s narration and dialogue.
- Keep the cover and character sheet silent, except for the optional cover introduction below.
- Do not narrate any words that only appear in a drawing unless specifically included here.

## Voice cast

| Label | Voice direction |
| --- | --- |
| ZOEY / NARRATOR | Kind, calm child; clear and reassuring. |
| MIA | Energetic, playful child. |
| EMILY | Thoughtful child; a little dramatic when she disagrees. |
| MOM | Warm and excited. |
| DAD | Warm and cheerful. |
